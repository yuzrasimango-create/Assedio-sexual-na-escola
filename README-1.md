# Escola Segura — Assédio Sexual nas Escolas

Site educativo e responsivo, em português, sobre identificação, prevenção e encaminhamento de situações de assédio sexual no contexto escolar. Inclui os elementos do grupo:

- Darciesa — 15
- Letícia — 29
- Sara — 45
- Yuzra — 49

## Como abrir
1. Extraia o ficheiro ZIP.
2. Abra a pasta `site_assedio_sexual_escolas`.
3. Abra `index.html` num navegador (Chrome, Firefox, etc.).

Não é necessária instalação nem ligação à internet para o funcionamento básico. A ligação à internet é necessária para abrir as fontes externas e carregar os tipos de letra.

## Publicar no GitHub Pages (telemóvel ou computador)
1. Entre em https://github.com e crie um repositório público, por exemplo `escola-segura`.
2. Carregue os ficheiros `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Seleccione a branch `main` e a pasta `/ (root)` e carregue em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na mesma página.

## Estrutura
- `index.html` — conteúdo e estrutura.
- `style.css` — cores, layout e adaptação a telemóveis.
- `script.js` — menu de navegação móvel.
- `README.md` — instruções.

## Nota importante
O conteúdo é educativo e não substitui aconselhamento jurídico, atendimento clínico ou investigação pelas autoridades. Os canais de apoio e procedimentos podem variar por localidade; confirme a disponibilidade dos serviços locais. O site não recolhe denúncias nem dados pessoais.
